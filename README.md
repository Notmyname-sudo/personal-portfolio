# Personal Portfolio: Maurice Phiri

A responsive black-and-white portfolio website for a Computer Science student, built for the Multimedia Tools and Applications module (Assignment 2).

## Sections

Home, About Me, Projects .

## Technologies

HTML5, CSS3 (Flexbox, Grid, transitions, keyframes), JavaScript, Montserrat font (Google Fonts). Developed in Visual Studio Code and hosted on GitHub Pages.

## Run locally

Open `index.html` in a browser.

## Publish

1. Create a repository named `personal-portfolio`.
2. Upload all files and folders.
3. Settings > Pages > Deploy from branch `main` / root.
4. Open the URL: `https://notmyname-sudo.github.io/personal-portfolio/`

Repository: https://github.com/Notmyname-sudo/personal-portfolio
